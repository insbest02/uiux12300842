# Amor AI

당신의 연애를 이해하는 AI 대화 코치, **Amor AI** 서비스 웹페이지입니다.
대화 분석, 상황별 답장 추천, 관계 코칭을 소개하고, 사용자가 직접 **AI 답장 상담**을 받아볼 수 있습니다.

- 배포 페이지: https://insbest02.github.io/uiux12300842/
- 저장소: https://github.com/insbest02/uiux12300842

## 서비스 개요

| 항목 | 내용 |
|---|---|
| 주요 사용자 | 연인·썸 상대에게 보낼 답장이 고민되는 20~30대 |
| 서비스 목적 | 대화와 상황을 이해해 관계에 도움이 되는 말과 행동을 추천 |
| 사용자 목표 | 내 상황에 맞는 답장 문장을 추천받기 |
| 핵심 행동 | 고민을 입력하고 관계 상황·답장 톤을 골라 추천 받기 |
| 완료 조건 | 완료 화면에 "✅ 상담 완료" 표시와 함께 닉네임·추천 답장이 나타남 |

## 사용자 흐름 (7주차)

```
① 시작 → ② 입력 → ③ 선택 → ④ 확인 → ⑤ 완료
```

| 단계 | 화면 | 사용자가 하는 일 |
|---|---|---|
| ① 시작 | 상담 안내 | "상담 시작하기" 클릭 |
| ② 입력 | 닉네임, 고민 내용 | 닉네임(필수)과 고민(필수, 10자 이상) 입력 |
| ③ 선택 | 관계 상황, 답장 톤 | 썸/연애 중/다툰 후 중 하나, 다정하게/솔직하게/유쾌하게 중 하나 선택 |
| ④ 확인 | 입력·선택 요약 | 내용 확인 후 "추천 받기", 또는 "고민 수정"·"이전"으로 돌아가 수정 |
| ⑤ 완료 | 추천 답장 | 결과 확인, "다시 상담하기"로 처음부터 |

화면 위쪽 진행 표시에서 현재 단계는 진한 분홍, 지나온 단계는 연한 분홍, 남은 단계는 회색으로 보입니다.

## 인터랙션 시나리오 (행동 → 이벤트 → 조건 → 화면 반응 → 다음 상태)

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
|---|---|---|---|---|
| 상담 시작하기 클릭 | click | 없음 | 입력 화면 표시, 닉네임 칸에 커서 | ② 입력 |
| 고민 입력 | input | 글자 수 10자 기준 | 글자 수 표시 (10자 미만 회색 → 이상 초록) | ② 유지 |
| 입력 단계 다음 클릭 | click | 닉네임 비어 있음 | 빨간 오류 문구 "닉네임을 입력해 주세요." + 빨간 테두리 | ② 유지 |
| 입력 단계 다음 클릭 | click | 고민 10자 미만 | "고민을 10자 이상 적어 주세요. (지금 N자)" + 빨간 테두리 | ② 유지 |
| 입력 단계 다음 클릭 | click | 모두 올바름 | 선택 화면 표시 | ③ 선택 |
| 관계 상황 선택 | change | 없음 | 고른 카드가 분홍 테두리로 강조, 오류 문구 사라짐 | ③ 유지 |
| 선택 단계 다음 클릭 | click | 상황 또는 톤 미선택 | 각 항목 아래 빨간 오류 문구 | ③ 유지 |
| 선택 단계 다음 클릭 | click | 모두 선택 | 확인 화면에 현재 값 요약 | ④ 확인 |
| 이전 / 고민 수정 클릭 | click | 없음 | 이전 단계로 이동, 입력·선택값 그대로 유지 | ② 또는 ③ |
| 수정 후 다시 다음 | click | 모두 올바름 | 확인 화면이 **수정한 값으로 다시** 채워짐 | ④ 확인 |
| 추천 받기 클릭 | click | 없음 | "✅ 상담 완료", 닉네임, 상황·톤에 맞는 추천 답장 표시 | ⑤ 완료 |
| 다시 상담하기 클릭 | click | 없음 | 입력·선택·오류·진행 표시 모두 초기화 | ① 시작 |

추천 답장은 관계 상황 3가지 × 답장 톤 3가지 = 9가지 문장 중에서 조건에 맞게 보여줍니다.

## 페이지의 다른 기능 (기존 유지)

| 주차 | 기능 | 이벤트 |
|---|---|---|
| 5주차 | 이메일 가입 신청 확인 | submit |
| 6주차 | 기능 탭 3개 (대화 분석 / 답장 추천 / AI 코칭) | click |
| 6주차 | 이메일 실시간 형식 검사 (문구·테두리·버튼 상태) | input |
| 6주차 | 상황별 추천 답장 (색상 변경) | change |

## 주차별 작업

| 주차 | 내용 |

| 2주차 | HTML 구조 (서비스 소개, 주요 기능, 이용 방법, 이미지, 가입 폼, 내부 이동 메뉴) |

| 6주차 | 이벤트 처리와 동적 UI (click / input / change, 탭 3개) |
| 7주차 | AI 답장 상담 흐름 (시작→입력→선택→확인→완료, 필수값 검사, 이전 단계 값 유지, 다시 시작) |

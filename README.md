# Amor AI

당신의 연애를 이해하는 AI 대화 코치, **Amor AI** 서비스 소개 웹페이지입니다.

- 배포 페이지: https://insbest02.github.io/uiux12300842/
- 저장소: https://github.com/insbest02/uiux12300842

## 주차별 작업

| 주차 | 내용 |
|---|---|
| 2주차 | HTML 구조 (서비스 소개, 주요 기능, 이용 방법, 이미지, 가입 폼, 내부 이동 메뉴) |
| 3주차 | CSS 디자인 (글자 크기, 색상, 배경색, 여백, 테두리) |
| 4주차 | 반응형 (viewport, 유동 너비, CSS Grid, 768px 미디어쿼리) |
| 5주차 | 이메일 가입 신청 확인 기능 (JavaScript) |
| 6주차 | 이벤트 처리와 동적 UI (click / input / change, 탭 3개) |

## 6주차 구현 내용

### 1. 구현한 이벤트

| 이벤트 | 대상 요소 | 동작 |
|---|---|---|
| `click` | 탭 버튼 3개 (대화 분석 / 답장 추천 / AI 코칭) | 누른 탭의 내용만 보여줌 |
| `input` | 이메일 입력칸 `#email` | 글자를 입력할 때마다 이메일 형식을 실시간 검사 |
| `change` | 상황 선택 `#situation` (썸 / 연애 중 / 다툰 후) | 선택한 상황에 맞는 추천 답장 표시 |
| `submit` | 가입 폼 | 가입 신청 완료 처리 (5주차 기능) |

### 2. 화면 변화 (문구 · 스타일 · 버튼 상태)

- **탭 (click)**
  - 스타일: 선택한 탭은 분홍 글자 + 분홍 밑줄 + 배경색으로 구분
  - 문구: 선택한 탭의 내용만 표시되고 나머지는 숨김
- **이메일 입력 (input)**
  - 빈 칸: 회색 안내 문구, 버튼 비활성화(회색)
  - 형식 오류: 빨간 안내 문구, 입력칸 빨간 테두리, 버튼 비활성화
  - 올바른 형식: 초록 안내 문구, 입력칸 초록 테두리, 버튼 활성화(분홍)
  - 신청 완료: 초록 완료 박스, 버튼 문구가 "신청 완료"로 바뀌고 비활성화
- **상황 선택 (change)**
  - 문구: 상황별 추천 답장 문장으로 변경
  - 스타일: 썸(보라) / 연애 중(분홍) / 다툰 후(파랑)로 박스 색상 변경
